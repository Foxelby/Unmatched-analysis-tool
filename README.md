# Unmatched-analysis-tool
A tool I was developing, inspired by the "matchup" function on Unmatched Club.

It is a website built using Streamlit and pandas libraries, which allow for faster database searches.

To run the code download the reposetry and run the command: python -m streamlit run "web page.py"

the datasets are created from Tabletop League (tabletopleague.com)
